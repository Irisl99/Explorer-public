# Alpha scope

This repository exposes a narrow, inspectable decision boundary: provisional evidence, clarifying outcomes, and human authorization for a confirmed teaching target.

It omits the complete application, assessment items, instructional content, learner records, human reviewer records, operational tools, deployment configuration, and evidence archives. It does not reproduce the hosted Alpha or establish comprehensive route coverage.

Explorer is in private Alpha with real learner testing. This public snapshot is a selected implementation reference, not a live application or a claim about the current private Alpha version. The synthetic examples do not reproduce learner sessions.

The source contract is bounded and includes Math-specific assumptions. Broader SAT coverage, content/assessment construct validity, real learner comprehension, completion, trust, outcomes, and generalization remain separate validation work. No learning efficacy, mastery, score improvement, retention, or product-market-fit claim follows from this repository.

All executable inputs are synthetic. No synthetic example is counted as a real learner. No screenshots are included because no public-safe media was selected for this snapshot.
